# Testbench Files

This folder contains the Verilog testbenches used to simulate and debug the AXI4-Lite slave interface modules.

## Planned Testbenches

- `write_tb.v` — Testbench for the Write Address (AW) channel.
- `read_tb.v` — Testbench for the Read module.
- `write_data_tb.v` — Testbench for the Write Data (W) channel.
- `wrt_rep_tb.v` — Testbench for the Write Response (B) channel.

Simulation results and waveform screenshots will be added as testing progresses.
